# SignBridge PK

Two-way Pakistani Sign Language communication assistant.

## Direction 1
PSL → Urdu/English → Text/Speech

## Direction 2
Urdu/English → PSL → 3D Avatar

## Training
Kaggle

## Application
You can easily install and run the application locally using the provided setup scripts.

**For Windows:**
1. Double-click `setup.bat` to install all dependencies (Python backend & Node.js frontend).
2. Double-click `start.bat` to run the servers.

**For Mac/Linux:**
1. Run `chmod +x setup.sh start.sh` in your terminal.
2. Run `./setup.sh` to install dependencies.
3. Run `./start.sh` to launch the servers.
